# AI Studio

iOS-приложение с двумя модулями: AI-чат на Dola API и генерация видео из фото по шаблону на PixVerse API.
Вокруг них онбординг, пейвол на Apphud, история чатов и видео, настройки.

UIKit, вёрстка кодом, iOS 16+, Swift 6 со strict concurrency. Единственная внешняя зависимость — ApphudSDK 4.6.1 (SPM, версия зафиксирована).

## Запуск

1. Откройте `AIStudio.xcodeproj` в Xcode 26 или новее (нужен SDK iOS 26 для Liquid Glass).
2. Скопируйте `AIStudio/Resources/Config/Secrets.example.xcconfig` в `Secrets.xcconfig` рядом и заполните ключами из задания:

   ```
   API_TOKEN = <Bearer-токен без слова Bearer>
   APPHUD_API_KEY = <ключ Apphud>
   ```

   Файл в `.gitignore`. Без него приложение запускается и не падает, но API отвечает отказом, а Apphud не стартует;
   в консоли будут строки `APIToken is empty` и `ApphudAPIKey is empty`.
3. Схема `AIStudio`, любой симулятор, ⌘R.

Покупки в симуляторе работают через `AIStudio.storekit`, он подключён к схеме. Сбросить тестовые покупки:
Debug → StoreKit → Manage Transactions.

## Архитектура

MVVM + Coordinator, зависимости собираются вручную в одном месте.

```
App       → всё (composition root)
Features  → Services, Domain, Core
Services  → Domain, Core
Data      → Domain, Core
Domain    → только Foundation
Core      → только системные фреймворки
```

- `AppContainer` — единственное место, где создаются конкретные типы. Экраны получают зависимости протоколами через `init`.
- `AppCoordinator` решает, куда перейти. Экран сообщает намерение замыканием (`onOpenResult`, `onBack`) и не знает о соседях.
- ViewModel хранит всё состояние экрана в одной `Equatable`-структуре (`@Published private(set) var state`),
  одноразовые события отдаёт через `events`. Данные экрана описаны как `Loadable<Value>`: загрузка, данные или ошибка,
  а не набор флагов. ViewModel не импортирует UIKit и тестируется без UI.
- ViewController только связывает: `bind()` подписывается на состояние, `render(_:)` переносит его во вью, `handle(_:)` реагирует на события.
- Фичи не ссылаются друг на друга. Общий UI лежит в `Core/DesignSystem`, общая логика — в `Services`.

## Ключевые решения

**Сеть.** `Endpoint<Response>` описывает запрос, `URLSessionAPIClient` его отправляет. Авторизация и `user_id`/`app_id`
добавляются интерсепторами; `user_id` — это ID пользователя Apphud. Ответы мапятся из DTO в доменные модели в репозиториях,
выше слоя Data DTO не выходят. Ошибки типизированы (`APIError`, доменные ошибки) и превращаются в текст только через
`UserFacingError`. Каждый ответ пишется в лог с методом, статусом и временем.

**Генерация видео.** Генерацией владеет `VideoGenerationCenter`. Он живёт всё время работы приложения, поэтому уход
с экрана ничего не отменяет. Центр загружает стартовый кадр, опрашивает статус через `Poller` (backoff, общий таймаут,
отмена, терпимость к коротким обрывам сети), скачивает результат локально (ссылка на сервере истекает) и ведёт историю.
После перезапуска незавершённые генерации продолжают опрашиваться. Причина неудачи (нет сети, нет кредитов, долгое
ожидание, ошибка рендера) сохраняется и показывается пользователю с кнопкой повтора.

**Видео и память.** Ячейки не создают плееры. `AutoplayController` держит фиксированный пул (6 в сетке, 2 в карусели)
и отдаёт плеер самым видимым `VideoPreviewView`. Ячейки без плеера показывают постер или фон карточки. Превью кэшируются файлами в Caches,
поэтому повторный показ не качает видео заново. В фоне и при уходе с экрана плееры отдают декодеры.
При долгой прокрутке сетки память не растёт.

**Фото.** Выбор через `PHPickerViewController`, перед ним запрос доступа, как в макете. Фото читается через ImageIO
с уменьшением: полноразмерный битмап в памяти не лежит. Перед загрузкой кадр обрезается под выбранный формат.

**Подписка.** ApphudSDK импортируется только в `ApphudSubscriptionService`, наружу видны доменные типы. Статус премиума
публикуется, поэтому после покупки доступ открывается без перезапуска. Премиум-действия (отправка в чат, генерация,
Replace, повтор генерации) идут через `PremiumGate`. Пейвол берёт продукты из пейвола `main` в Apphud, а если его нет,
показывает планы Year и Month из Product hub.

**UI.** Цвета, шрифты (Inter), отступы, радиусы и длительности — только из токенов `Core/DesignSystem/Tokens`.
Liquid Glass на iOS 26 через `GlassView` и `GlassMaterial`, на iOS 16–25 — тонированный системный блюр.
Смена состояний — кроссфейдом, загрузка — skeleton'ами, высота контейнеров не прыгает. На iOS 18+ карточки
раскрываются zoom-переходом. Учтены Reduce Motion, Dynamic Type и VoiceOver.

## Отступления от макета и API

- **Format (16:9, 9:16, 1:1).** У `template2video` нет параметра формата: видео повторяет стартовый кадр.
  Поэтому фото обрезается под выбранный формат перед загрузкой.
- **Quality.** Показываются качества, которые поддерживает шаблон по API (360p–1080p). 4K из макета API не умеет.
- **Лоадер генерации.** В макете Lottie; нарисован нативно, чтобы не тянуть зависимость.
- **Плашка «SAVE 80%».** Процент задан макетом. Цены в карточках настоящие и приходят из StoreKit.
- **Contact us, Privacy Policy, Usage Policy, Terms of Use** — заглушки: ссылок на документы нет.
- **Тестовый сервер** любому пользователю возвращает один и тот же чат «Sandbox chat», поэтому история чатов не пустая
  с первого запуска. Пустое состояние видно, если удалить этот чат свайпом.

## Тесты

150 unit-тестов без сети и без UI: ViewModel всех экранов, `VideoGenerationCenter`, `Poller`, репозитории и маппинг DTO,
сетевой слой (кодирование тел, multipart, разбор ошибок, клиент), обрезка изображений, кэш каталога.
Зависимости подменяются фейками из `AIStudioTests/Fakes`.

```
xcodebuild -project AIStudio.xcodeproj -scheme AIStudio -destination 'platform=iOS Simulator,name=iPhone 17' test
```

## Отладка

В схеме есть выключенные аргументы `-startScreen <экран>`: `onboarding`, `paywall`, `main`, `chat`, `history`,
`settings`, `videoTemplates`. Включённый аргумент открывает экран сразу после запуска.

## Структура

| Папка | Что внутри |
|---|---|
| `App` | `AppContainer`, `AppCoordinator`, конфигурация |
| `Features` | Экраны: `<Name>ViewModel`, `<Name>ViewController`, вью в `Views/` |
| `Services` | Подписка, генерация видео, кэш, уведомления, доступ к фото |
| `Data` | Dola и PixVerse: эндпоинты, DTO, репозитории; локальное хранение |
| `Domain` | Модели и протоколы репозиториев |
| `Core` | Дизайн-система, сеть, медиа (плееры, кэш видео, загрузка фото), хранилище |
| `AIStudioTests` | Тесты, фейки, фикстуры |

Проект описан в `project.yml` (XcodeGen). `AIStudio.xcodeproj` уже сгенерирован и лежит рядом, XcodeGen для запуска
не нужен; после добавления файлов — `xcodegen generate`.
